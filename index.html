Environment

1 · Can it write?

Writes a file of real size to OPFS on the main thread, then in a Web Worker. Both paths matter: older Safari only supports the Worker one.

Not run yet.

2 · Can it play a real video?

Downloads an MP4 to OPFS and plays it back from disk. Paste a URL to one of your own files, or leave blank to make a synthetic file (writes and reads, but will not play).

Not run yet.

3 · Does it survive?

The one that actually decides this. Stamp a marker, leave the device alone for a week without opening the site, then come back and check. Eviction is the risk, not the API.
